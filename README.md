# Snake Game (C++)

A console-based implementation of the classic **Snake Game**, developed in **C++**.
This project recreates the traditional arcade gameplay while demonstrating core programming concepts such as game loops, collision detection, file handling, and real-time keyboard input.

---

## Features

* Real-time snake movement using keyboard controls
* Supports **WASD** and **Arrow Keys**
* Snake grows after eating fruit
* Random fruit spawning
* Boundary collision detection
* Self-collision game over logic
* Score tracking system
* Persistent score record using text files
* Menu-based game navigation

---

## Technologies Used

* C++
* Windows Console
* File Handling (`fstream`)
* Keyboard Input (`conio.h`)
* Cursor Control / Console Rendering

---

## Controls

| Key   | Action     |
| ----- | ---------- |
| W / ↑ | Move Up    |
| S / ↓ | Move Down  |
| A / ← | Move Left  |
| D / → | Move Right |

---

## How to Run

1. Open project in a C++ compiler (Visual Studio / CodeBlocks / Dev-C++)
2. Compile the source file
3. Run executable
4. Choose from menu:

   * Start Game
   * View Record
   * Exit
